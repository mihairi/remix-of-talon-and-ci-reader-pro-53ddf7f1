# Architecture rules
- Reconcile talon page evidence in the standalone Python service and expose comparison/review metadata separately from values; the frontend only maps and displays the corrected schema, because multipage OCR and annex interpretation need server-side processing.
- Bound unfolded talon annex context using printed annex/inspection headings, retaining the full annex for handwriting review and original coordinates in evidence; canonicalize valid plate separators without inventing identifier characters.
- Accept full or standalone classic CI MRZ data rows with applicable field check digits; normalize nationality O/0 only in its slot, derive birth date only from validated CNP, retain and flag conflicting valid printed CNPs, preserve MRZ provenance and never recover redacted fields.
- Parse names from TD2 row one and TD1 row three only in complete MRZ context; validate alphabet/separators and reject labels, compare regardless of printed confidence, return MRZ names on disagreement while retaining earlier values/scores and review, because MRZ names have no checksum and composite checks do not cover them.
- Apply date requirements in the Python date-policy module; skip reverse-only expiry only with positive new-front text evidence, keep unknown layouts unresolved, and pass field status to the UI without inventing dates or confidence.
- Deliver the standalone Python OCR server as a versioned source archive; keep processing and API logic there, not in the React application, because OCR requires native Python dependencies.
- With fallback enabled, missing/invalid critical CI fields bypass call/noise/page-option limits and use a single-field page request if no safe crop remains; explicit global disable, redaction and unavailable-side rules prevail, so required attempts do not imply fabricated values.
- Use local label-anchor extraction and field validation before optional model fallback; reject full/split/truncated label translations and detected redacted fragments as values, validate name and issuer neighbors, join only complete spatially supported series/number pairs and check redactions across their boxes, retain unresolved-name/issuer/serial anchor evidence and anchored address-subfield evidence and explain skipped routing; send bounded crops for unresolved fields; a completely empty unredacted field with no reliable crop may send the page with a single-field prompt (configurable), because unrecognized fields must still reach the model while validation and null model confidence guard against fabrication.
- Keep field values backward-compatible and return provenance in a separate field_metadata map; unknown model confidence must remain null, never inferred from validation or the earlier OCR score. Aggregate MRZ confidence only when all contributing scores are known; text-only merge passes must preserve unknown confidence instead of comparing nulls.
- Configure accent normalization and observed-text review thresholds in the Python service's shared JSON; preserve original OCR scores and structured-field validation so spelling tolerance never fabricates confidence or bypasses identity checks.
- Represent confirmed address-subfield absence as an empty value with explicit local-rule status and decision confidence, separate from OCR recognition scores, so routing skips absent fields without inventing text.
- Measure Python activity wall time per request with a monotonic clock, accumulating retries and failed model calls; report lock waiting separately and exclude debug persistence from processing totals.
- Preload Paddle models at application startup; expose shared model/CPU/orientation settings, retain compatible Latin recognition, and choose performance defaults only after sample field comparison; time OCR substages without changing recognition results.
- Run same-model FP32 ONNX/OpenVINO through pinned PaddleX preprocessing and decoding adapters; crop only reliable enclosing borders and skip page orientation only after upright anchor evidence, counting uncertain retries; refuse to start instead of falling back to plain Paddle, because acceleration must retain field and redaction behavior.
- Talon sub-row anchors, blank-on-document C.2 status and observation-text rejection live in the Python service; the frontend shows the CIV series from X or Y in one card and renders label-rule absence without a score, because talon versions print CIV at either position.
